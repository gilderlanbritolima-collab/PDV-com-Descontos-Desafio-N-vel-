# PDV-com-Descontos-Desafio-N-vel-
Sistema de PDV em Python que calcula o valor final de compras com descontos progressivos: 20% para clientes com 65 anos ou mais e 10% extra se o valor já descontado passar de R$ 100. Aceita várias compras até digitar 0, valida negativos, guarda tudo em lista e mostra um resumo do dia com total bruto, descontos e total final.
